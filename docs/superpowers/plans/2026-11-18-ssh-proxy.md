# SSH Proxy Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a deployable SSH-compatible server that exposes an interactive local shell over a configurable non-22 TCP port without user authentication, protected by an optional source-CIDR allowlist.

**Architecture:** A Go CLI loads YAML configuration, persists an Ed25519 SSH host key, and runs a TCP listener. Permitted connections complete an SSH handshake with `NoClientAuth`; a session handler exposes one PTY-backed shell and rejects every unsafe SSH capability.

**Tech Stack:** Go 1.22+, `golang.org/x/crypto/ssh`, `github.com/creack/pty`, `gopkg.in/yaml.v3`, standard-library testing, systemd.

package config

import ("fmt"; "net"; "os"; "path/filepath"; "gopkg.in/yaml.v3")

type Config struct {
 Listen string `yaml:"listen"`; HostKeyPath string `yaml:"host_key_path"`
 AllowCIDRs []string `yaml:"allow_cidrs"`; Shell string `yaml:"shell"`; networks []*net.IPNet
}
func Load(path string) (Config, error) {
 b, err := os.ReadFile(path); if err != nil { return Config{}, fmt.Errorf("read config: %w", err) }
 var c Config; if err = yaml.Unmarshal(b, &c); err != nil { return Config{}, fmt.Errorf("parse config: %w", err) }
 if c.Listen == "" || c.HostKeyPath == "" { return Config{}, fmt.Errorf("listen and host_key_path are required") }
 if _, _, err = net.SplitHostPort(c.Listen); err != nil { return Config{}, fmt.Errorf("invalid listen address: %w", err) }
 if c.Shell == "" { c.Shell = "/bin/sh" }
 if !filepath.IsAbs(c.HostKeyPath) { c.HostKeyPath = filepath.Join(filepath.Dir(path), c.HostKeyPath) }
 for _, raw := range c.AllowCIDRs { _, n, e := net.ParseCIDR(raw); if e != nil { return Config{}, fmt.Errorf("invalid allow_cidrs entry %q: %w", raw, e) }; c.networks = append(c.networks, n) }
 return c, nil
}
func (c Config) Allows(ip net.IP) bool { if len(c.networks)==0{return true}; for _, n := range c.networks { if n.Contains(ip) { return true } }; return false }
```

package hostkey

import ("crypto/ed25519"; "crypto/rand"; "fmt"; "os"; "path/filepath"; "golang.org/x/crypto/ssh")

func LoadOrCreate(path string) (ssh.Signer, error) {
 if b, err := os.ReadFile(path); err == nil { return ssh.ParsePrivateKey(b) } else if !os.IsNotExist(err) { return nil, fmt.Errorf("read host key: %w", err) }
 if err := os.MkdirAll(filepath.Dir(path), 0700); err != nil { return nil, err }
 _, private, err := ed25519.GenerateKey(rand.Reader); if err != nil { return nil, err }
 pem, err := ssh.MarshalPrivateKey(private, ""); if err != nil { return nil, err }
 f, err := os.OpenFile(path, os.O_WRONLY|os.O_CREATE|os.O_EXCL, 0600)
 if os.IsExist(err) { return LoadOrCreate(path) }; if err != nil { return nil, err }
 if _, err = f.Write(pem.Bytes); err != nil { _ = f.Close(); return nil, err }; if err = f.Close(); err != nil { return nil, err }
 return ssh.NewSignerFromKey(private)
}
```

On `shell`, require a prior PTY request, then start `exec.Command(shell, "-l")` with:

```go
ptmx, err := pty.StartWithSize(cmd, &pty.Winsize{Cols:uint16(cols), Rows:uint16(rows)})
go io.Copy(ptmx, channel)
go io.Copy(channel, ptmx)
```

On completion or disconnect, close the PTY, terminate a still-running child, wait for it, send an SSH `exit-status` request, and close the channel. Map and forward only `INT`, `TERM`, `HUP`, and `QUIT` signal requests. Add `github.com/creack/pty`; do not add SFTP or forwarding packages.
